**ReaderHub v3.62** — високопродуктивний настільний менеджер і каталогізатор електронних бібліотек для Windows (`win-x64`) із миттєвим повнотекстовим пошуком **SQLite FTS5**, автоматизованим формуванням централізованого сховища книг `\libofbooks`, системою віртуальних поличок, смарт-колекцій та редагуванням метаданих.

---

## ⚡ Ключові можливості ReaderHub v3.62

- **🔍 Миттєвий повнотекстовий пошук SQLite FTS5 (`bookhub.db` у WAL-режимі):**
  - Надшвидка індексація десятків тисяч книг і документів із пошуком за назвою, автором, серією, ISBN/DOI, тегами, категоріями та повнотекстовим вмістом за `< 10 мс`.
  - Автоматичний фоновий моніторинг директорій (`FileSystemWatcher`) та виявлення дублікатів за SHA-256 хешем із можливістю безпечного злиття (Merge) записів, тегів і нотаток.
- **📁 Керована бібліотека `\libofbooks`:**
  - У вікні «Налаштування» реалізовано опцію **«Бажаєте створити бібліотеку?»**, яка дозволяє автоматично консолідувати всі знайдені книги в єдину впорядковану папку `\libofbooks`.
  - Підтримується вибір режиму консолідації — **Скопіювати** або **Перенести** знайдені книги до папки `\libofbooks`.
  - За замовчуванням папка `\libofbooks` створюється поруч із файлом `ReaderHub.exe`, також передбачено можливість вказати власний шлях на будь-якому диску.
- **🏷 Метадані, Віртуальні полички та Смарт-колекції:**
  - Повноцінний редактор метаданих (назва, автор, категорія, теги, рік видання, видавництво, серія та номер тому, ISBN, DOI, обкладинка).
  - Прив'язка зовнішніх конспектів, файлів коду та шпаргалок до будь-якої книги у бібліотеці, а також експорт конспектів у формат Markdown (`.md`) для **Obsidian** та резервне копіювання каталогу в один клік (`Backups\`).
- **🌍 Мультимовність та кастомізація:**
  - 5 адаптивних тем оформлення (*Obsidian Dark*, *Nord Dark*, *OLED Black*, *Warm Sepia*, *Nord Light*) та миттєве перемикання між 10 мовами інтерфейсу (*UK, EN, PL, DE, ES, FR, IT, PT, JA, ZH*).

## 📖 Інтеграція з автономним переглядачем AllReaderBook

Інсталятор (`ReaderHub_Setup_v3.62_x64.exe`, за прапорцем у майстрі встановлення) та портативна версія (`ReaderHub_Portable_v3.62_x64.zip`) комплектуються автономним надшвидким переглядачем [**AllReaderBook**](https://github.com/RomanMyrovych/AllReaderBook) для миттєвого відкриття знайдених у каталозі книг через виклик зовнішнього процесу (`AllReaderBook.exe "path_to_book"`). Якщо під час встановлення користувач знімає прапорець встановлення `AllReaderBook`, `ReaderHub` використовує власне вбудоване вікно перегляду.

## 📚 Формати, що індексуються каталогізатором

| Категорія | Підтримувані розширення |
| :--- | :--- |
| **Електронні книги та скани** | `.pdf`, `.epub`, `.fb2`, `.mobi`, `.azw`, `.azw3`, `.cbz`, `.djvu` |
| **Документи та технічні нотатки** | `.docx`, `.odt`, `.rtf`, `.txt`, `.md`, `.html`, `.htm` |

## 💻 Системні вимоги

- **ОС:** Windows 10 / Windows 11 (x64)
- **ОЗП:** від 2 ГБ RAM
- **Середовище виконання:** .NET 9.0 Desktop Runtime (для компактної Portable-версії) або не потребує нічого (при встановленні через автономний інсталятор `ReaderHub_Setup_v3.62_x64.exe`).

## 🛠 Збірка з вихідного коду та пакування

```powershell
# 1. Компіляція рішення у конфігурації Release
dotnet build .\BookHub.sln -c Release

# 2. Створення портативної збірки ReaderHub v3.62 (Publish\ReaderHub_Portable_v3.62_x64.zip)
powershell -ExecutionPolicy Bypass -File .\Publish-Portable.ps1

# 3. Створення інсталятора ReaderHub_Setup_v3.62_x64.exe
powershell -ExecutionPolicy Bypass -File .\Build-Installer.ps1
```
